## 2. 运行链路

```mermaid
flowchart LR
  U[用户问题] --> P[QueryParser]
  P --> B[prompt_builder]
  ENV[.env] --> CFG[config]
  CFG --> LLM[LLMClient]
  CFG --> DB[DatabaseClient]
  B --> LLM
  LLM --> DB
  DB --> F[ResultFormatter]
  CASES[test_cases.json] --> EV[Evaluator]
  DB --> EV
```

`main.run` 逐步：

```mermaid
flowchart TD
  Q[user_question] --> PARSE[parser.parse]
  PARSE --> VAL{validate?}
  VAL -->|否| E0[success=False 无 sql]
  VAL -->|是| BP[build_prompt 默认无 RULES]
  BP --> GEN[llm.generate_sql]
  GEN -->|抛错| SYS[CLI 系统错误]
  GEN --> EX[db.execute]
  EX -->|成功| FMT[formatter.format]
  EX -->|异常| E1[返回 sql + error]
```

## 4. error_analyzer 逻辑

```mermaid
flowchart TD
  IN[sql + question + error_msg?] --> SYN{error_msg 像语法?}
  SYN -->|是| S[SYNTAX 短路]
  SYN -->|否| D[_detect_error_types]
  D --> F[field]
  F --> J[join]
  J --> TI[time]
  TI --> FI[filter]
  FI --> AG[agg]
  AG --> PICK[取 list 第一项]
  PICK -->|空| U[UNKNOWN]
  PICK -->|有| TAB[根因/建议查表]
```

时间检查：对 `sql.lower()` 找大写 `DATE_SUB` → 相对时间题易恒真。
