# 核心模块逻辑思维导图

交互版（Cursor 聊天旁打开）：`docs/canvases/chatbi-module-logic.canvas.tsx`

详细文字拆解见 `docs/02-核心模块逻辑拆解.md`。

## 模块关系

```mermaid
flowchart LR
  ENV[.env] --> CFG[config.py]
  CFG --> LLM[llm_client]
  CFG --> DB[database]
  PAR[query_parser] --> MAIN[main]
  PB[prompt_builder] --> MAIN
  LLM --> MAIN
  DB --> MAIN
  FMT[result_formatter] --> MAIN
  DB --> EV[evaluator]
  CASES[test_cases.json] --> EV
  PB -.-> EV
  LLM -.-> EV
  ERR[error_analyzer]
  SCH[schema_generator]
```

虚线：仅 `evaluator.__main__` 组合，类本身不 import Prompt/LLM。`error_analyzer` / `schema_generator` 无引用。

## 各模块控制流

### config.py

```mermaid
flowchart TD
  A[import 模块] --> B[load_dotenv]
  B --> C[DB_CONFIG]
  B --> D[LLM_CONFIG]
  C --> P{password 空或 None?}
  P -->|是| D1[落到 123qwe]
  P -->|否| D2[用环境变量]
```

### query_parser.py

```mermaid
flowchart TD
  I[user_input] --> S[strip]
  S --> V{len > 0?}
  V -->|是| OK[is_valid True]
  V -->|否| NG[is_valid False]
  OK --> X[main 丢弃 parsed 只用校验]
```

### prompt_builder.py

```mermaid
flowchart TD
  Q[question + 三开关] --> SYS[system 角色句]
  SYS --> R{rules 或 guards?}
  R -->|是| SYS2[追加严格遵守]
  R -->|否| SCH[必含 SCHEMA]
  SYS2 --> SCH
  SCH --> RU{use_rules?}
  RU -->|是| RUL[插入 RULES]
  RU -->|否| FS{use_few_shot?}
  RUL --> FS
  FS -->|是| FEW[插入 Few-shot]
  FS -->|否| GU{use_guards?}
  FEW --> GU
  GU -->|是| GD[插入 ERROR_GUARDS]
  GU -->|否| UQ[用户问题 + 要求1-6 永远在]
  GD --> UQ
  UQ --> R2{rules 或 guards?}
  R2 -->|是| S7[第7条]
  R2 -->|否| OUT[请直接输出 SQL]
  S7 --> OUT
```

### llm_client.py

```mermaid
flowchart TD
  M[system + user] --> API[chat.completions.create]
  API --> RAW[content.strip]
  RAW --> RE["re.sub 剥 ```sql / ```"]
  RE --> SQL[声称纯 SQL]
```

### database.py

```mermaid
flowchart TD
  S[sql] --> C[connect]
  C --> E[cursor.execute]
  E --> COL{description?}
  COL -->|有| N[列名列表]
  COL -->|无| Z[空列名]
  N --> F[fetchall]
  Z --> F
  F --> CL[finally close]
```

### result_formatter.py

```mermaid
flowchart TD
  IN[columns + rows] --> EMP{rows 空?}
  EMP -->|是| T[查询结果为空]
  EMP -->|否| W[算每列 max 宽 +2]
  W --> H[表头 ljust]
  H --> SEP[分隔线]
  SEP --> R[数据行]
```

### main.py ChatBISystem.run

```mermaid
flowchart TD
  Q[user_question] --> P[parse]
  P --> V{validate}
  V -->|否| E0[输入为空]
  V -->|是| B[build_prompt few_shot]
  B --> G[generate_sql]
  G --> TRY[try execute]
  TRY -->|成功| F[format 成功 dict]
  TRY -->|异常| E1[sql + error]
```

### evaluator.py evaluate_one

```mermaid
flowchart TD
  C[case + generator] --> G[生成 SQL]
  G -->|异常| EG[SQL 生成失败]
  G --> EX[Exact Match 空白折叠]
  EX --> Q1[执行 expected_sql]
  Q1 -->|失败| EE[金标环境坏]
  Q1 --> Q2[执行 generated_sql]
  Q2 -->|失败| ES[生成 SQL 执行失败]
  Q2 --> EQ[_results_equivalent]
  EQ --> OUT[execution_match]
```

```mermaid
flowchart TD
  EQ[_results_equivalent] --> C1{列数相同?}
  C1 -->|否| F[False]
  C1 -->|是| C2{行数相同?}
  C2 -->|否| F
  C2 -->|是| C3{任一侧非纯聚合?}
  C3 -->|是| N[按列名 dict 排序比]
  C3 -->|否| V[按位置元组排序比]
```

### error_analyzer.py

```mermaid
flowchart TD
  IN[sql question error_msg] --> S{像语法?}
  S -->|是| SYN[SYNTAX]
  S -->|否| D[field 然后 join 然后 time 然后 filter 然后 agg]
  D --> P[取第一项]
  P -->|空| U[UNKNOWN]
  P -->|有| T[查表根因建议]
```

### schema_generator.py

```mermaid
flowchart TD
  CON[connect 自读 env] --> T[SHOW TABLES]
  T --> LOOP[每表]
  LOOP --> COL[SHOW FULL COLUMNS]
  LOOP --> FK[INFORMATION_SCHEMA 外键]
  COL --> STR[拼 Schema 字符串]
  FK --> STR
```

### text2sql v0 / v1 / v2

```mermaid
flowchart LR
  V0[v0 无 Schema] --> V1[v1 Schema + Few-shot]
  V1 --> V2[v2 CoT + 更严约束]
```

三版各自调 API、剥围栏、只打印 SQL，不走 `ChatBISystem`。
