CHATBI LEARNING OUTLINE

ChatBI 课程大纲

来源：飞书 Wiki · 智优未来 · 文档更新于 2025-07-02 · 共 6 个阶段 / 30 课时

课程主线

本系列课程围绕一个真实企业级 ChatBI 实战项目，从 0 到 1 逐步推进，每一节解决一个具体问题，并最终构建出一个完整的企业级系统。

第一阶段：项目导论与系统蓝图（3 课时）

第 1 课：项目背景与真实企业 AI 落地痛点

介绍制造业财务分析场景，演示传统 BI 痛点，明确 ChatBI 要解决的核心问题。

第 2 课：从“利润分析”到 AI 系统：三层能力拆解

拆解 Query 理解、数据理解、分析能力三层架构，用真实案例说明为什么不能使用简单 Text2SQL 解决。

第 3 课：企业级 ChatBI 系统架构设计与 MVP 范围定义

讲解整体架构图，定义 MVP 边界，标注各模块输入输出，明确课程最终交付目标。

第二阶段：最小可运行系统 MVP（6 课时）

第 4 课：从 0 搭建数据环境：制造业财务数据建模与 SQL 实战

创建核心表并导入模拟数据，编写基础 SQL 验证数据模型正确性。

第 5 课：让 LLM 第一次“说人话变 SQL”：Prompt 工程实战

手写 few-shot prompt，注入 schema 信息，调用 LLM 生成 SQL 并执行验证。

第 6 课：打通“问 → 查 → 答”：第一个可运行的 Text2SQL 系统

整合 query 解析、SQL 生成、数据库执行、结果返回完整链路，产出首个 demo。

第 7 课：为什么 SQL 总是错？真实错误案例拆解与修复

分析字段选错、Join 错误、时间计算错误等典型案例，通过修改 prompt 修复问题。

第 8 课：构建 SQL 生成评估体系：Execution Accuracy 实战

设计测试用例集，编写评估脚本计算 execution accuracy，量化系统表现。

第 9 课：引入指标知识：为什么“利润”算不对

分析利润口径差异问题，构建简单指标定义表，为 RAG 做准备。

第三阶段：系统服务化与前端交互（3 课时）

第 10 课：系统服务化改造：从脚本到 FastAPI 服务

将 Text2SQL 脚本封装为 REST API，设计请求/响应结构，实现可调用服务。

第 11 课：ChatBI 前端界面实战：构建可交互的对话页面

搭建简单聊天界面，实现用户提问、系统返回结果、展示 SQL 和数据的完整交互。

第 12 课：前后端联调与接口设计：让系统真正“可用”

联调前端与 FastAPI 服务，处理异常情况和错误提示，完成第一个“能用的”ChatBI 系统。

第四阶段：让系统“理解业务”（Schema Linking + RAG）（8 课时）

第 13 课：企业数据为什么难用？Schema Linking 问题剖析

分析字段歧义、表选择困难等真实问题，理解 Schema Linking 的核心价值。

第 14 课：表级召回实战：Embedding 相似度检索正确数据源

实现基于 embedding 的表召回函数，用真实 query 测试召回准确率。

第 15 课：字段语义匹配实战：解决“amount 到底是哪种金额”

构建字段匹配逻辑，结合 embedding 相似度和业务规则，选出正确的字段。

第 16 课：多表 Join 路径自动推理：让 SQL 不再乱连表

实现基于外键关系的 join 路径自动推导，验证复杂查询的 join 正确性。

第 17 课：Schema Linking 完整链路实现与效果评估

整合表召回、字段匹配、join 推理，构建完整 Schema Linking 模块，对比优化前后 SQL 准确率。

第 18 课：指标知识库构建实战：让 AI 理解利润 / 毛利 / ROI

设计指标元数据结构，构建包含计算公式、业务定义、数据源的指标知识库。

第 19 课：RAG + Text2SQL 融合：Prompt 注入指标知识

实现指标检索与 prompt 注入，让 SQL 生成“算对利润”，对比 RAG 前后的生成质量。

第 20 课：Schema Linking + RAG 综合优化与系统升级

将 Schema Linking 和 RAG 整合到现有系统，完成完整优化链路，评估最终效果。

第五阶段：复杂分析能力（Agent）（6 课时）

第 21 课：为什么一个 SQL 解决不了问题？复杂分析任务拆解

以“利润下降原因”为例，拆解复杂分析任务的多步骤特性，对比单 SQL 与多步骤方案。

第 22 课：从 0 实现 Query 拆解器：Task Decomposition 实战

用 LLM 将复杂问题拆解为可执行的子任务列表，设计拆解 prompt 和输出格式。

第 23 课：构建 Plan-and-Execute Agent 框架

实现 Plan 生成、步骤执行、结果汇总的核心 Agent 框架，支持多步骤 SQL 执行。

第 24 课：多 SQL 执行与中间结果管理

实现步骤间数据传递，管理中间查询结果，确保多步骤执行的连贯性。

第 25 课：结果总结与自动分析报告生成

基于多步骤执行结果，用 LLM 生成结构化分析报告，包含数据洞察和行动建议。

第 26 课：复杂案例完整实战：利润下降原因分析系统

端到端实现“利润下降原因分析”完整流程，从 query 输入到报告输出，验证 Agent 效果。

第六阶段：工程化与企业落地（4 课时）

第 27 课：权限与安全设计：企业数据为什么不能随便查

设计数据权限控制方案，实现行级 / 列级权限过滤，保障数据安全。

第 28 课：SQL 错误处理与性能优化

实现 SQL 执行异常捕获、超时处理、慢查询优化，提升系统稳定性。

第 29 课：系统扩展与模块化设计：如何支撑更多数据源

设计可扩展架构，支持新增数据源、指标、业务规则，降低维护成本。

第 30 课：项目复盘与简历包装：如何讲清你的企业 AI 项目

回顾完整项目链路，提炼技术亮点、核心面试题清单，指导简历撰写和面试表达。
